# SPA Oyonnax — proposition d’identité visuelle

Maquette autonome en HTML, CSS et JavaScript, sans dépendance ni compilation. Ouvrir `index.html` dans un navigateur, ou lancer depuis ce dossier :

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## Direction visuelle

Palette inspirée du logo transmis : bleu SPA approché `#207aad`, bleu profond `#155a82`, encre `#183d55`, blanc cassé `#faf9f5`, bleu très pâle `#eaf3f8`. Le bleu est une approximation visuelle du logo, pas une référence de charte officielle. Les tons chauds des photographies et illustrations préservent une ambiance accueillante. Titres Playfair Display et texte DM Sans (Google Fonts, avec alternatives Georgia et Arial sans réseau). Composition éditoriale, photographies généreuses, illustrations douces et appels à l’action sobres. Interface responsive, filtres d’animaux, fiches modales, navigation mobile et prise en charge du mouvement réduit.

## Adapter à WordPress

Les sections peuvent devenir des groupes de blocs : en-tête, rencontre principale, animaux, présentation, soutien, contact. Les couleurs sont centralisées dans `style.css`. Remplacer les contenus fictifs, illustrations et photo générée par des données et photographies autorisées du refuge avant toute publication. Vérifier les horaires, les modalités d’adoption et les liens officiels. Aucun formulaire ni paiement ne fonctionne dans cette maquette ; les liens de contact renvoient au site officiel.

Cette création est une proposition indépendante, pas une copie ni un audit du site existant, qui n’était pas accessible depuis l’environnement. Les animaux sont fictifs. La photo du chien est générée et les illustrations SVG sont créées pour la maquette.
