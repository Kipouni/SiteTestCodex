# Guide de reproduction de la maquette sous WordPress

Le guide principal utilise maintenant **Elementor gratuit**, conformément à la méthode choisie.

👉 **[Ouvrir le guide Elementor pas à pas](GUIDE-ELEMENTOR.md)**

Il détaille les conteneurs, widgets, couleurs, polices, dimensions et réglages mobile de chaque section. Aucun CSS personnalisé ni abonnement Pro n’est nécessaire pour construire les sections principales.

L’ancien [guide des blocs natifs WordPress](GUIDE-BLOCS-WORDPRESS.md) reste disponible pour référence. Le fichier `style-wordpress.css` est réservé à cette ancienne méthode : ne l’utilise pas pour la version Elementor.
